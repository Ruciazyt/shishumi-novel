# 史书墨

历史小说AI辅助创作工具，帮助作者还原历史细节、查阅资料、引用古诗词。

## 功能特性

- 📖 **项目管理** - 创建和管理多部小说作品，按时代背景分类
- ✍️ **AI辅助写作** - 润色文本、还原历史细节、历史资料查询
- 📜 **诗词推荐** - 根据场景智能推荐古诗词，支持一键插入
- 🏯 **时代背景库** - 预设唐宋元明清等朝代的历史细节参考

## 技术栈

- React Native (Expo)
- TypeScript
- 通义千问 API (qwen-turbo)
- AsyncStorage 本地存储

## 开发

```bash
npm install
npx expo start
```
